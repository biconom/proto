# CHANGELOG: 14 Августа 2026 (proto v0.3.10)

Одно аддитивное значение в `Topic` — новый топик уведомлений
**«достигнут ранг стейкинга»**.

> ✅ **Не breaking.** Добавлено только новое значение enum'а с очередным
> свободным номером; существующие номера не тронуты. Старые клиенты просто
> не знают о нём и получают его как неизвестное значение.

---

## `biconom/client/notification_preferences/notification_preferences.proto`

```protobuf
enum Topic {
    // …
    TOPIC_BONUS_RECEIVED = 20;
    TOPIC_STAKING_RANK_ACHIEVED = 21;   // ← новое
}
```

### Зачем отдельный топик, а не ветка `TOPIC_BONUS_RECEIVED`

Частоты отличаются на два порядка: доход по депозиту — 12 уведомлений на
каждый депозит, достижение ранга — максимум 12 **за всю жизнь аккаунта**.
Один переключатель на оба события заставлял бы партнёра выбирать между
«шумом каждый месяц» и «пропустить редкое важное событие».

### Доставка

Только **Telegram** (`optional`, включён по умолчанию). Email и push для
этого топика запрещены политикой: событие редкое и «наградное», ему не
нужен ни push на все устройства, ни письмо.

Комментарий в `TOPIC_BONUS_RECEIVED` дополнен: стейкинг-начисления входят
в его umbrella (виды `staking_income` и `staking_rank_premium` в поле
`kind` payload'а).
