# LotteryAdminService — управление лотереей «5 из 36»

Алгоритм тиража и расписание — `biconom/client/lottery/lottery.md`.

| Метод | Право | Что делает |
|---|---|---|
| `GetSettings` | ADMIN_LOTTERY | текущие настройки для следующих тиражей |
| `UpdateSettings` | ROOT | включение, цена, маска допуска, фонд — для тиражей, открывающихся после правки |
| `ListDraws` / `GetDraw` | ADMIN_LOTTERY | продажи, собранный WinTime, победители и статус начислений (после раскрытия) |

Инварианты:
- админ не видит `server_seed` и числа до раскрытия;
- фонд и цена открытого тиража не меняются;
- начисления повторяются сервером автоматически до успеха; повтор не дублирует
  выплату (`last_error` показывает последнюю ошибку).
